## Description

M5PHET and news-signal are two complementary open-source repositories:

Program and typed-ML foundation: https://github.com/harveybc/M5PHET
Concrete Laya integration: https://github.com/harveybc/news-signal

M5PHET proposes five interoperable research fronts: classification,
regression/multi-horizon forecasting, representation and unsupervised learning,
reinforcement learning, and causal inference. Each uses task-appropriate
open-source engines, typed outputs, explicit uncertainty semantics and matched
evaluation, with distributed optimization through the existing DOIN ecosystem.
It currently implements the classification result contract, not five engines.

news-signal consumes that contract and wraps local Laya for asset-specific news
relevance, event and financial-tone classification. It includes a pinned SDK
adapter, timestamp and response validation, provenance hashes, an offline demo
and tests. Results are shadow-only. Real-weight financial performance and
calibration remain unmeasured; MT5 demo and Alpaca paper integration are planned.
We welcome review of the concrete integration and collaboration on the broader
typed-ML interfaces. No universal-model or profitability claim is made.
