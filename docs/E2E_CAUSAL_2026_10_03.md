# E2E causal (ATE) through M5PHET, with persistence — 2026-10-03

Second family proven by `tests/test_family_e2e.py` after the regimes case of 2026-10-01: the real `causal_inference`
provider (entry point `m5phet.providers`), a retained EconML study read from disk, a typed answer, stored, read back
unchanged by a new application on the same state directory.

## Chain

request (envelope `area: causal`, `state.state_ref = causal-ate:<digest>`, `as_of` pinned, no attachment) ->
typed contract (`validate_task`, question types `ate` and `cate` declared by the provider) -> real provider
(`causal_inference_provider.chat:M5PHETCausalProvider`, loads the study by digest from `CAUSAL_INFERENCE_STATE_DIR`)
-> typed validated output (per-question `type`/`status`, `execution_authorized: false`) -> persistence (workbench state
directory) -> E2E test.

## What the test asserts (beyond type)

- `ate`: `effect_size`, `confidence_interval`, `unit`, `population`, `assumptions` equal the study artifact, which the
  test reads from disk independently and digest-checks; the estimate lies inside its own interval; `development: true`
  is carried (the study is SYNTHETIC/DEVELOPMENT).
- `cate` asked of a study fitted without an effect modifier: `REFUSED` / `NOT_ESTIMABLE`, with a reason and no number;
  the message is `PARTIAL`, never `OK` over a refusal.
- Reproducibility: the same envelope under a second request id returns identical answers.
- Persistence: a new application on the same state directory returns the stored message byte for byte.
- Point-in-time: the same envelope at a clock before the study existed refuses every question (`NOT_ESTIMABLE`,
  "after the requested clock"), message `REFUSED`.
